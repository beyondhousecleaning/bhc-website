Paper on ink, 15.81:1. The focus ring is the shipped base indicator — this component adds no :focus-visible rule of its own.

The failure this component's contract prevents

A skip link whose target has no tabindex="-1" moves the viewport and leaves focus in the header, so the next Tab press returns to the first nav item. It looks like it works. The root layout renders <main id="main" tabindex="-1"> for exactly this reason, and this component must be the first element inside <body>, before the header.
