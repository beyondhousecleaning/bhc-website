Why this component exists

There is exactly one anchor per card. The whole-card hit area comes from a stretched ::after on that same anchor, not from an outer wrapper link — an <a> may not contain interactive content, so a wrapper plus a title link is parsed into two sibling links and a six-card grid announces twelve.
