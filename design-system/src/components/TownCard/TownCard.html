The data-file bug this prevents

Every card above names a post town or a named suburb. A bare postcode district is never a town name — nobody lives in or searches for one — and a full postcode is forbidden outright by D4 and Lock 5, because the registered office is residential. From Phase 3 this grid is generated from a data file, so a single bad row would publish it across every locations page at once. Lock 5 scans the package source and SC-2d scans the built HTML.
