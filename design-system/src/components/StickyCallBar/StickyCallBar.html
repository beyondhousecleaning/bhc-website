Two rules that are easy to miss

The component declares body { padding-bottom: 64px } inside its own narrow media query. The bar is position: fixed, so nothing in normal flow can reserve space for it, and without that rule it would cover the footer's last row on every mobile page. Above the breakpoint the bar is display: none — removed from the accessibility tree, not merely painted out of view, so a desktop keyboard user cannot tab into an invisible bar.

Never — a call label carrying the wrong form of the number

Call 07861 936533

Shown once, inline, so the failure is recognisable. The digit-equality check normalises a leading 44 and not a leading 0, so this label disagrees with its own href and fails. The shipped label is the single word Call with no digits at all, which is out of that clause's scope, plus aria-label="Call Beyond House Cleaning" so the link is not ambiguous out of context. A digit-bearing label here would have to read exactly +44 7861 936533.
