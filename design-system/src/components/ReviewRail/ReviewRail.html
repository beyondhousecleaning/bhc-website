Without data — this is what every Phase 2 page renders

Nothing. The component returns null on an empty array — no rail, no empty rail, no "no reviews yet" line. Review data arrives in Phase 4, and until then every template composes this with reviews={[]} so that Phase 4 changes a data file rather than eight templates.

Why there are no arrow buttons

An arrow needs a pointer handler, which needs a client component, which turns the client-boundary gate red for a control the platform already provides. The track is overflow-x: auto with scroll-snap-type: x mandatory and it carries tabindex="0", role="group" and an aria-label, which is what makes it reachable by keyboard. That explicit tab stop is correct only because ReviewCard contains no focusable children.
