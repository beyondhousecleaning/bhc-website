RSC FLIGHT-PAYLOAD COUNTING TRAP — measured, and it will silently corrupt any count-based lock:
the serialised flight payload is inlined in the HTML, so bare substring greps DOUBLE-count.
  `application/ld+json` bare                -> 6   (wrong)

Tag-form (`<h1`, `<footer`) and attribute-form (`href="tel:`, `aria-current="page"`) regexes are
