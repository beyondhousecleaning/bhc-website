```js
// The extractor, measured in 03-RESEARCH.md: the markup half is 27.7 KB of a 76.7 KB page, so
// splitting on the flight-payload marker first is a 3.5x reduction before any regex runs.
// 348 pages strip in 55 ms.
const bodyText = (html) =>
  html.split('self.__next_f')[0]
    .replace(/<script[\s\S]*?<\/script>/g, ' ')
    .replace(/<style[\s\S]*?<\/style>/g, ' ')
    .replace(/<nav[\s\S]*?<\/nav>/g, ' ')      // breadcrumbs, jump links, footer columns
    .replace(/<header[\s\S]*?<\/header>/g, ' ')
    .replace(/<footer[\s\S]*?<\/footer>/g, ' ')
    .replace(/<[^>]*>/g, ' ')
    .replace(/\s+/g, ' ')
    .trim();
```

§10.3's strip list also removes *what's included*, the ProcessSteps bodies, the FAQ answers, the
review quotes and the interlink labels — **everything in it is shared by 40 or more pages, so

The hashed exhaustive Jaccard, measured 2.5× faster than the `Set<string>` form and the shape that
stays comfortable if the corpus doubles:

```js
const N = 5;
const h32 = (s) => { let h = 2166136261; for (let i = 0; i < s.length; i++) { h ^= s.charCodeAt(i); h = Math.imul(h, 16777619); } return h | 0; };
const shingles = (text) => { const w = text.split(/\s+/); const seen = new Set();
  for (let i = 0; i + N <= w.length; i++) seen.add(h32(w.slice(i, i + N).join(' ')));
  return Int32Array.from(seen).sort(); };
const jaccard = (A, B) => { let hit = 0, x = 0, y = 0;
  while (x < A.length && y < B.length) { if (A[x] === B[y]) { hit++; x++; y++; }
    else if (A[x] < B[y]) x++; else y++; }
  return hit / (A.length + B.length - hit); };
```

Do not build the pair list as an array — 60,378 tuples is needless allocation. Loop
`for (i) for (j = i+1)` and accumulate scores.

**The town-masked control** — the anti-mad-libs gate, and the reason it exists: if the pages were
variable substitution, masking the town would collapse them toward identity. Replace every published
town's display name and every locality name with a single placeholder token, recompute the medians,

**Restore the audit's second metric.** The 2026-08-06 audit ran 5-gram Jaccard **and** TF-IDF cosine
and published both (live site: Jaccard 0.049, cosine 0.120). Delta 23 as written keeps only Jaccard,
which is **lexical**: eight paraphrases of one 300-word passage share almost no 5-grams and measure
about 0.05. Given that 39% of this phase's corpus is exactly "eight variants per service", that is the
corpus's highest-risk region and Jaccard alone is blind there. Cosine costs 2.3 s at 348 documents,
measured.

**The ceiling is an absolute hard-coded literal: 0.150 for the all-pairs median and 0.150 for the
within-service mean.** It is the live site's published 0.120 plus headroom, and plan 03-17 task 3
already measured the same corpus against the same two numbers three waves earlier — so this gate is
confirming a known-good corpus, not calibrating against it.

Do **not** compute the ceiling from the measured corpus at runtime, and do not set it to "measured
plus a margin". A threshold derived from the data it guards asserts only that the data agrees with
itself — the identical argument this repo applies to `MIN_APP_ROUTES` and to delta 19's index bound.
You may tighten the literal below 0.150 if plan 03-17's recorded figures make that safe; record the
figures and the reasoning in the file, and never raise it.

**What the cosine figures should look like, measured before this plan shipped.** A model of §10.2's
exact block structure — 21 towns × 6 services, the Latin-square `(a, b)`, genuinely distinct
fragments — measures **all-pairs median 0.0000, all-pairs mean 0.0195, within-service median 0.0000,
within-service mean 0.0666**, and a **worst pair of 0.3926**. The two ceilings therefore have roughly
2× headroom on the figures the design produces.

**The worst cosine pair is deliberately NOT capped, and 0.39 is not a failure.** Two same-service
pages sharing a variant index share block 3 *or* block 4 verbatim — up to 390 of ~995 words — by
design, and TF-IDF cosine reports that sharing directly. §10.3's worst-pair ceiling of 0.35 is a
**Jaccard** ceiling and already governs that population; a cosine worst-pair ceiling below about 0.45
would fail on correct work. Cap the median and the mean, which is where paraphrase shows up, and
report the worst pair without asserting on it.


**Do not implement the sampling fallback** §10.3 describes. It triggers at 60 s and the full run is
under 7 s at twice this corpus size.
